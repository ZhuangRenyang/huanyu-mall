# ADR-088：订单导出补「售后进度」列

- 日期：2026-11-14
- 状态：已采纳
- 关联：ADR-073（列表角标）、ADR-057（订单导出）

## 背景

ADR-073 给订单列表加了售后进度角标（待审退款 / 等买家寄回 / 退货待收货），
但导出 CSV 没有这一列。商家导出对账时，界面上看到的和表里的不一致。

## 决策

1. 导出**复用** `listActiveRefundsByOrderIds`：一次 IN 查询，与列表同一口径，
   不另写一套「哪些算在途」的判定。
2. 列名「售后进度」放在「件数」之后、「金额」之前：先看货、再看售后，最后看钱。
3. 文案与列表角标一致；没有在途售后单时为空串，不是「无」——空单元格在对账时更好筛。
4. 导出测试的列数断言从 23 改为 24，并保留「含逗号留言仍不裂列」的校验。

## 后果

- API：导出多一列，表头 24 列
- 测试：导出用例更新列数断言（2 处）
- 无迁移

## 遗留

- 已完成的售后（同意/拒绝/已退款）不进导出：导出是「当前处理中」快照，
  历史售后在退款管理页查
