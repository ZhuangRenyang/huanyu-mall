# ADR-091：微页面富文本——服务端白名单清洗，前端才敢渲染 HTML

- 日期：2026-11-14
- 状态：已采纳
- 关联：ADR-082（微页面纯文本）、ADR-080（轮播链接白名单）

## 背景

微页面第一版只支持纯文本（空行分段），能覆盖「关于我们 / 售后说明」这类简单单页，
但排版能力为零：不能加粗、不能标题分层、不能列表、不能插图。CRMEB 的微页面
用的是富文本编辑器。

## 决策

### 1. 富文本是「服务端清洗 → 前端信任」的信任链

引入 `sanitize-html`（Node 生态最成熟的白名单清洗库），在 **theme 模块服务层**
入库前清洗，前端渲染时才敢用 `dangerouslySetInnerHTML`。

信任链必须单向且闭环：**只有服务端清洗过的 HTML 才允许进库、才允许进渲染**。
任何绕过清洗的写入路径都是漏洞，所以清洗放在 service 层（create / update），
不是路由层、更不是前端。

### 2. 白名单只给排版，不给执行能力

允许：`p / div / h1–h6 / br / strong / b / em / i / u / s / ul / ol / li / blockquote /
table / pre / code / hr / span / figure / img / a`。

一律剥掉：`script`、事件属性（`on*`）、`javascript:` 协议、`style` 里的
`position / display / expression`（只保留 `text-align` 与 `text-indent`）。

链接强制 `rel="noopener noreferrer nofollow"` + `target="_blank"`（既是安全也是 SEO）；
图片 `src` 只放行 `http / https / data:`（外链图或粘贴的 base64 图）。

### 3. `content_format` 区分纯文本与富文本，老数据零迁移

新增 `theme_micro_page.content_format`（默认 `plain`）：

- `plain`：老行为，前端仍按空行分段渲染 —— 已存在的纯文本页面**不受影响**；
- `html`：已清洗富文本，前端直接渲染。

不加这个字段会出事故：老纯文本里的 `<` `>` 一旦被当 HTML 渲染会被吃掉/误解。

### 4. 编辑器是极简 contenteditable + execCommand

后台装修页提供「纯文本 / 富文本」切换，富文本用 contenteditable + 工具栏
（加粗/斜体/下划线/标题/列表/清除格式），`execCommand` 生成 HTML。

不做完整富文本编辑器（图片上传、表格编辑、字数统计）：那是 wangEditor/UEditor
的产品级能力，先跑通「编辑 → 清洗 → 渲染」这条安全闭环，编辑器后续可替换，
清洗层不变。

## 后果

- theme：迁移 `0011_micro_page_rich_text.sql`（`content_format`）、`rich-text.ts`
  （`sanitizeRichText` / `normalizeContentFormat`）、服务层 create/update 清洗
- API：后台 create/update 接收 `content_format`；店面 `getStorePage` 下发 `content_format`
- SDK：`createMicroPage / updateMicroPage` 带 `content_format`
- 后台：装修页微页面「纯文本 / 富文本」切换 + 极简工具栏
- 店面：`/p/{slug}` 按 format 渲染，`globals.css` 加 `.rich-text` 排版样式
- 依赖：catalog 新增 `sanitize-html@2.18.2` + `@types/sanitize-html@2.16.2`
- 测试：api +5（script/事件/javascript: 被剥、链接 rel/target、img 白名单、style 白名单、
  format 归一化）；api 340、storefront 46；迁移 62

## 遗留

- **图片上传**：现在富文本插图靠外链或粘贴 base64；接入 file 模块的图片上传
  需要编辑器配合（光标处插入图片 url）
- **完整编辑器**：表格编辑、字数统计、撤销栈都还没有，属编辑器增强
- **图片点击查看大图 / 懒加载**：纯展示增强，非安全必需
- **清洗规则测试的回归兜底**：白名单改动后要重跑 rich-text.spec.ts 确认没放开危险标签
