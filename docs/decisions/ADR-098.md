# ADR-098：电子发票——手工登记版，不动钱不动订单

- 日期：2026-11-14
- 状态：已采纳
- 关联：ADR-030（工作台）、ADR-051（售后）、ADR-097（统计）

## 背景

顾客要发票，此前只能私聊客服、商家手工记在 Excel 里；顾客下次想看开没开，
还得再问一遍。淘宝和 CRMEB 后台都有独立的「发票管理」：顾客在订单页提交抬头，
商家开好票登记号码，顾客回订单页就能看到。

接税务服务商（税盘 / 电子发票平台）需要资质、税号与外部接口，属不可控的外部依赖。
但**业务闭环**（申请 → 待开票 → 已开票 / 已拒绝，双方都能查）与外部依赖无关，
可以先用人工方式跑通。

## 决策

### 1. 只做手工登记，不做自动开票

`order_invoice` 记业务状态，「开票」这个动作在线下完成，商家回后台**登记发票号**。

将来接入服务商时只替换「登记号码」那一步（改成调用开票接口 + 回写 PDF 地址），
状态机与单据结构不变 —— 这是把不可控的外部依赖挡在业务模型之外。

### 2. 状态机三态：pending → issued / rejected

```
pending ──开票──> issued   （终态：号码登记后不能改）
   └────拒绝──> rejected   （终态：原因顾客可见）
```

不设「作废/重开」：红冲换开要走税务流程，属线下动作；系统里再开一张就是两张票，
账对不上。要重开就线下处理，系统状态保持不变。

### 3. 一张订单只能一张票（unique index 兜底）

`uq_order_invoice_order` 唯一索引 + 服务层先查一次给友好错误。
淘宝同此：一张订单开一次票，重复申请会开出两张。

### 4. 三条准入条件

- **只有已收款订单能开票**：`payment_status === "captured"`。
  未付款就开票，等退款时票要红冲，两头都麻烦。
  > 这里踩过一次概念坑：`order.status` 的 `paid` 与 `payment_status` 的
  > `captured` 是两套枚举，判「钱到账了没」必须看 `payment_status`。
- **企业必须填税号**：没有税号的增值税发票不能报销，等于白开。
- **金额取订单总额快照**，客户端不传值（铁律 13）；订单后续改价不影响已提交的票。

### 5. 拒绝必须写原因，顾客可见

与退款拒绝同一纪律：拒绝是「对顾客不利的决定」，必须给出可读的理由，
否则顾客只会看到「被拒了」而不知道为什么。

### 6. 开票不动钱、不动订单状态

登记发票号只写 `invoice_no / issued_at / status`。
订单状态与资金流水一律不碰 —— 开票是财务动作，不是交易动作。
这也是把发票放进**订单域**而不是新建模块的原因：它跟着订单走，
离开订单没有任何意义。

## 后果

- order：迁移 `0011_invoice.sql`（`order_invoice` + 唯一索引）、模型 `orderInvoice`、
  `InvoiceDTO / InvoiceQuery / InvoiceType / InvoiceStatus`、仓储 6 个方法、
  服务 `requestInvoice / getInvoiceByOrder / listInvoices / countInvoicesByStatus /
  issueInvoice / rejectInvoice`、7 个领域错误
- API：店面 `POST /store/orders/:id/invoice`、`GET /store/orders/:id/invoice`；
  后台 `GET /admin/invoices`、`POST /admin/invoices/:id/issue`、`/reject`（orders 权限）
- SDK：`requestOrderInvoice / getOrderInvoice / listInvoices / issueInvoice / rejectInvoice`
- 后台：订单组新增「发票管理」页（待开票 / 已开票 / 已拒绝 / 全部 + 登记开票 / 拒绝对话框）
- 店面：订单详情「发票」区块（申请表单 / 待开票 / 已开票号码 / 拒绝原因）
- 测试：api +5（申请金额取订单、重复申请 409、企业缺税号 400、未收款 409、
  开票与重复开票 409、拒绝后顾客可见原因）；api 350、order 34、storefront 46；迁移 66

## 遗留

- **接税务服务商**：电子发票开具 / PDF 回传 / 红冲，属外部集成，有资质才能做
- **部分开票**：一单多商品只开其中几件；现在按整单金额开
- **发票下载**：issued 后只能看号码，没有 PDF 可取
- **开票信息记忆**：常客每次都要重填抬头，可存「常用抬头」到客户档案
