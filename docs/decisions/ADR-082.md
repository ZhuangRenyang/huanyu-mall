# ADR-082：微页面——装修的最后一块

- 日期：2026-11-14
- 状态：已采纳
- 关联：ADR-079（首页模块）、ADR-080（轮播）、ADR-081（链接选择器）

## 背景

装修前四块已交付：主题、首页模块、轮播、链接选择器。
缺「关于我们 / 售后说明」这类单页 —— 商家只能把内容塞进商品详情或公告条。

## 决策

### 1. 第一版只做「标题 + 纯文本正文」

不做富文本编辑器：富文本要处理粘贴清洗、图片上传、XSS 白名单，是独立一轮。
纯文本按**空行分段**，已经能覆盖「关于我们 / 售后说明 / 配送政策」。

正文原样存库，渲染时 React 自动转义 —— 不引入 `dangerouslySetInnerHTML`，
从根上没有 XSS 面。

### 2. slug 有格式门槛，不做中文转拼音

`^[a-z0-9](?:[a-z0-9-]*[a-z0-9])?$`，2–60 位。拼音转换错得多（多音字），
错了就是死链，让商家自己填。

### 3. 草稿不给店面

`GET /store/pages/:slug` 只查 `is_published = true`；草稿与不存在一样返回 404，
不泄露未上线内容。

### 4. 链接选择器扩展 type=page

微页面可被轮播、后续页面互相引用；只列已发布的，链接到草稿等于给顾客一个 404。

## 后果

- theme：迁移 `0006_micro_page.sql`、模型、仓储/服务/契约、`normalizeSlug`
- API：`/admin/settings/pages` 增删改查（审计）；`GET /store/pages/:slug`
- SDK：`listMicroPages / createMicroPage / updateMicroPage / deleteMicroPage / getStorePage`
- 后台：装修页新增「微页面」（列表、发布开关、删除、创建表单）
- 店面：`/{locale}/{channel}/p/{slug}` 渲染，空行分段
- 链接选择器新增「微页面」类型
- 测试：api +2（slug 非法 400、草稿 404），全量 327 通过；迁移 57

## 遗留

- 富文本与图片：下一轮做，需要清洗与上传
- 页面排序与分组：现在按更新时间；页面多了要分类
- SEO：标题与描述字段还没做
